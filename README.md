# Block Buddies

A playful place-value number game for kids — a single self-contained HTML page.

- **Park** — type a number and watch your block buddy build itself; slide buddies together to add, lift them to break apart
- **Run** — a runner game collecting ones, tens and hundreds
- **Quiz** — quick number challenges
- **Book** — stickers and numbers you've met

## Play

Open `index.html` in any browser. No build step or dependencies.
